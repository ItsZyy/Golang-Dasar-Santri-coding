## 03. Tipe Data Dasar Golang

Praktik pembelajaran mengenai tipe data dasar dalam bahasa pemrograman Go (Golang).

### Materi Praktik

1. **Integer (int)** — Mengenal tipe data bilangan bulat.
2. **Tipe Data Default** — Deklarasi variabel tanpa menentukan tipe data secara eksplisit.
3. **Boolean** — Mengenal tipe data `true` dan `false`.
4. **Konversi String** — Mempelajari konversi tipe data ke string.
5. **Zero Value** — Memahami nilai awal otomatis pada variabel yang belum diberi nilai.
6. **String** — Mengenal tipe data untuk menyimpan teks.

### Source Code

Setiap materi memiliki file `main.go` masing-masing di dalam foldernya.
