## 04. Variable Golang

Praktik pembelajaran mengenai penggunaan dan deklarasi variabel dalam bahasa pemrograman Go (Golang).

### Materi Praktik

1. **Multiple Declaration** — Mendeklarasikan beberapa variabel sekaligus.
2. **Variable Outside Function** — Mendeklarasikan variabel di luar fungsi.
3. **Short Declaration** — Mendeklarasikan variabel menggunakan operator `:=`.
4. **Type Inference** — Menentukan tipe data variabel secara otomatis berdasarkan nilai yang diberikan.
5. **Keyword var** — Mendeklarasikan variabel menggunakan keyword `var`, dengan atau tanpa menentukan tipe data secara eksplisit.

### Source Code

Setiap materi memiliki file `main.go` masing-masing di dalam foldernya.
